# notes



* **harmonic analysis**: these notes are mostly based on lectures of monica visan and rowan killip for math 247 at ucla. there is some additional content, particularly concerning the littlewood-paley theory, based on terry tao's lecture notes + exercises. 
* **multilinear algebra:** i wrote these up for personal education.
* **pde:** basic linear and non-linear pde, mostly following lectures of daniel tataru and sung-jin oh for math 222 at ucb. 
* **ode:** based on the first chapter of tao's dispersive pde book.
* **seminar notes**: these are notes for learning seminar talks i gave at ucb. read with extreme scepticism, as the details can be quite sketchy.
